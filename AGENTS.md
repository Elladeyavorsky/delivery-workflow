# Reglas de este repositorio

Estas reglas aplican al contribuir a `delivery-workflow`, no al usar el paquete instalado en otro proyecto.

## Issues

Al crear o rellenar una issue de este repositorio:

1. Título en inglés, empezando por un verbo.
2. Cuerpo en español con la plantilla del tipo (`feat`, `fix`, `docs`, `refactor`, `test`, `chore` o `knowledge`).
3. Añade además una sección `## Decisión` con:
   - qué se decide;
   - por qué;
   - qué alternativas se descartaron y por qué.

La plantilla global de `manage-issue` no trae esa sección: en este repo hay que escribirla igual.

## Flujo

Para ramas, commits, pull requests y comprobaciones, sigue [CONTRIBUTING.md](CONTRIBUTING.md).
