### Herramienta: ENTREVISTA_LIBRE

- **Descripción**: Úsala cuando la idea no depende de este repositorio, o cuando `entrevista-con-repo` ya dejó decisiones que el repositorio no responde. En ese caso va después. No la uses para crear la issue, la rama ni la pull request. No tiene script ni llama a GitHub.
- **Inspiración**: [grill-me](https://www.skills.sh/mattpocock/skills/grill-me), de Matt Pocock. Esta versión pregunta en tandas, cada pregunta con su respuesta recomendada. No hace falta instalar la original.

#### Cómo entrevistar

1. Haz las preguntas que necesites en cada tanda, cada una con su respuesta recomendada. Espera las respuestas antes de la tanda siguiente.
2. No abras el código para contestar. Esta skill no recorre el repositorio.
3. Devuelve qué hay que hacer y cómo se comprueba. El resumen único lo cierra `help-me-to-think`.
